Cada pasta tem o código do agente e um README próprio. Os agentes usam a função `executar_agente` da Parte 4 do [notebook do minicurso](../notebook/Agente_IA_Python_Minicurso.ipynb), então o jeito mais simples é rodar o notebook até a Parte 4 e depois colar o código do agente numa célula nova.
